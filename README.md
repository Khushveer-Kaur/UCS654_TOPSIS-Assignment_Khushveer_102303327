## Overview

This repository contains the complete implementation of the **TOPSIS (Technique for Order Preference by Similarity to Ideal Solution)** algorithm as part of the UCS654 assignment.  
The assignment is divided into three parts:

1. Command Line Interface (CLI) based implementation  
2. Python Package (PyPI-style) implementation  
3. Web Service implementation using Flask  

Each part is implemented, documented, and tested independently.

---

##  Part 1: CLI Based TOPSIS

- Implements TOPSIS as a command-line tool
- Accepts input CSV file, weights, and impacts
- Outputs result CSV with TOPSIS score and rank

 Detailed instructions are available in `Part-1-CLI-TOPSIS/README.md`

---

## 🔹 Part 2: Python Package (PyPI Style)

- TOPSIS implemented as a reusable Python package
- Can be installed locally and imported in other projects
- Proper package structure with `setup.py` and `LICENSE`

 Detailed instructions are available in `Part-2-PyPI-Package/README.md`

---

##  Part 3: Web Service (Flask)

- Web-based TOPSIS implementation using Flask
- User can upload CSV, enter weights & impacts
- Computes TOPSIS score and sends result via email
- Successfully deployed using **Render**

 Live URL : <https://topsis-web-service-bq7q.onrender.com/>
